# Amazon Clothing Sales Analysis — Power BI

## Project Overview

This project analyzes Amazon clothing sales data to understand sales
performance, customer behavior, product performance, discount strategies,
reviews, and delivery performance.

## Business Objectives

- Analyze overall sales and revenue performance
- Evaluate discount strategies
- Analyze product, category, and brand performance
- Understand customer behavior by age, region, and device
- Analyze customer ratings and delivery performance

## Dataset

The dataset contains 20,000+ clothing sales records covering Men's,
Women's, Kids', and Baby categories.

## Data Cleaning & Transformation

- Checked data quality
- Identified missing values
- Removed duplicate records
- Handled missing values
- Standardized categorical fields
- Created delivery-type categories

## Data Modelling

A star-schema model was created using:

- Amazon Sales table
- Calendar table

The Calendar table includes weekday information.
